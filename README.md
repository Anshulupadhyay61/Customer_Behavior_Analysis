## 📌 Project Overview

Customer Shopping Behavior Analysis is an end-to-end data analytics project focused on understanding customer purchasing patterns using transactional data from **3,900 customer purchases across multiple product categories**.

The project uses Python for data cleaning and exploratory data analysis (EDA), PostgreSQL for business-oriented SQL analysis, and Power BI to build an interactive dashboard.

The primary objective is to identify meaningful patterns in customer spending, product preferences, discount usage, customer loyalty, and subscription behavior to support data-driven business decisions.

## 🎯 Business Objectives

- Analyze customer purchasing and spending patterns.
- Compare revenue generated by different customer demographics.
- Understand the relationship between discounts and purchasing behavior.
- Identify top-rated and frequently purchased products.
- Segment customers based on their purchase history.
- Evaluate subscription behavior and repeat purchases.
- Build an interactive dashboard for business insights.
- Provide actionable recommendations to improve business performance.

## 📊 Dataset Overview

The dataset contains customer shopping transaction records.

| Dataset Attribute | Details |
|---|---|
| Total Records | 3,900 |
| Total Columns | 18 |
| Missing Values | 37 |
| Missing Value Column | Review Rating |

### Key Features

- **Customer Demographics:** Age, Gender, Location, Subscription Status.
- **Purchase Details:** Item Purchased, Category, Purchase Amount, Season, Size, Color.
- **Shopping Behavior:** Discount Applied, Promo Code Used, Previous Purchases, Frequency of Purchases.
- **Customer Feedback:** Review Rating.
- **Order Information:** Shipping Type.

## 🐍 Python: Data Cleaning & Exploratory Data Analysis

The following preprocessing operations were performed:

1. **Data Loading:** Imported the dataset using Pandas.
2. **Initial Exploration:** Used `df.info()` and `df.describe()` to understand the dataset.
3. **Missing Data Handling:** Imputed 37 missing Review Rating values using the median rating of each product category.
4. **Column Standardization:** Renamed columns using snake_case conventions.
5. **Feature Engineering:**
   - Created `age_group` by categorizing customer ages.
   - Created `purchase_frequency_days` from purchase data.
6. **Data Consistency:** Checked redundancy between `discount_applied` and `promo_code_used` and dropped `promo_code_used`.
7. **Database Integration:** Connected Python with PostgreSQL and loaded the cleaned DataFrame.
